# AI 创作者平台导航

按生成能力分模块收录，优先国内可用。只收录各品类中使用人数较多、较为常用的平台，热门度不足的不再收录，因此各模块数量不等（24–30 条）。排序默认国内优先 → 使用人数 → 评分。使用人数仅少数平台有公开数据（QuestMobile / Sensor Tower / 公司财报），无公开数据的条目不做数字臆测；消费档只与同类型平台比较，为同类内相对位置，不跨模块换算。

单文件静态站：无构建、无依赖、无外部请求，直接打开 `index.html` 即可使用。

## 每条记录包含

- **平台名称与官网**：点击卡片任意位置在新标签打开
- **生产商与国家**：按厂商总部或主要运营主体标注
- **消费档**：很高 / 高 / 中 / 低 / 很低，同类内相对位置
- **评分**：10 分制，编辑估计
- **擅长方向**：影视级、二次元、音频、工程级代码、轻量级代码、0 代码智能体、办公、设计等标签
- **使用人数**：有公开数据时显示月活与口径来源
- **访问网络**：可直连 / 需境外网络（VPN）

## 功能

- **搜索**：平台名、厂商、国家、能力关键词
- **筛选**：能力、地区、消费档、网络、已收藏，多维可叠加
- **排序**：推荐（国内优先 → 使用人数 → 评分）、评分从高到低、使用人数从多到少
- **收藏**：点击平台名右侧五边形图标，数据保存在浏览器 localStorage，刷新不丢

## 数据口径

### 消费档

只在同一模块内比较，不跨模块换算。视频类的「中」与对话类的「中」不是同一金额。

| 档位 | 在本类中的位置 | 说明 |
| --- | --- | --- |
| 很高 | 该类最高 | 企业年约、按席位售卖或最高档订阅，个人难以长期自付 |
| 高 | 高于该类中位 | 专业订阅，订阅后可稳定商用 |
| 中 | 该类主流付费档 | 有免费额度，付费门槛不高 |
| 低 | 低于该类中位 | 免费额度 + 几十元级会员 |
| 很低 | 该类最低 / 免费 | 免费，或仅承担本地算力成本 |

人民币参考（编辑归纳，非报价）：视频生成 ¥100–200/月；图片生成、代码生成、对话与推理、音频与音乐、办公与文档、设计与原型 ¥70–150/月；智能体与低代码 ¥150–300/月。

每个模块至少有一个「高」或「很高」、一个「低」或「很低」的条目，但不强制出现「很高」，避免造成该类普遍昂贵的误读。

### 评分

10 分制，按平台整体给出，同一平台跨模块一致。加权维度：

| 维度 | 权重 |
| --- | --- |
| 能力上限 | 30% |
| 国内可用性 | 25% |
| 稳定与生态 | 20% |
| 性价比 | 15% |
| 公开口碑 | 10% |

评分为编辑估计，不是第三方评测排名，不替代实际使用体验。

### 使用人数

仅少数平台有可核查数据，来源包括：QuestMobile 2026-09 AI 原生 App 榜、Sensor Tower 2026-05 估算、OpenAI / Alphabet / 微软等公司财报与官方公告。

周活、月活、累计用户、付费席位四种口径不可混排，页面只作量级参考。**没有公开数据不等于平台小**，只代表没有可核查来源。

## 本地使用

```bash
git clone https://github.com/JLFjiao/ai-creator-platform-nav.git
cd ai-creator-platform-nav
# 直接双击 index.html，或：
python -m http.server 8000
```

## 说明

- 平台域名、套餐与可用地区会变更，以官方页面为准。
- 「需境外网络」仅描述访问条件，实际可用性以平台与当地法规为准。
- 商用前请核对生成内容的授权范围、训练数据与肖像/商标风险。
